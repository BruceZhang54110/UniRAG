# Contract: 首页 UI 契约

**Feature**: `009-rag-service-home` | **Date**: 2026-10-11

本契约把 spec 的 FR/SC 落成可核对、可断言的前端行为约定。实现与测试均以此为准。

---

## 1. 路由契约

| 路径 | 视图 | 本期实现程度 | 备注 |
|---|---|---|---|
| `/` | 服务首页（提问台 + 知识导航） | **完整实现** | 默认入口 |
| `/chat?q=<问题>` | 问答上下文占位 | 实现（占位语义，见 §2.4） | 由首页提交问题跳转 |
| `/documents` | 文档库占位 | 实现（"即将上线"占位） | 导航可点，避免死链 |
| `/jobs` | 任务中心占位 | 实现（"即将上线"占位） | 同上 |
| 文档详情 | 首页内 `Drawer` | 完整实现 | **不占路由**，关闭后仍在 `/` |

**约束**：
- 未知路径回落到首页（而非空白页）。
- 部署到静态托管时需支持 SPA fallback（刷新 `/chat` 不得 404）；该要求写入 `quickstart.md` 的部署说明，不由本期实现承担。

---

## 2. 视图与交互契约

### 2.1 整体框架

- 使用 `ConsoleShell`（侧栏可折叠、记住折叠状态）+ `ConsoleNav`（高亮当前路由）。
- 顶栏右侧固定为 **主题切换**；**不得**出现租户选择器、租户名、租户编码、租户切换文案。
- 侧栏项：首页、问答、文档库、任务中心（后两者指向占位页）。

### 2.2 提问框（核心，FR-003/004/005/006）

| 行为 | 契约 |
|---|---|
| 初始状态 | 居中，最大宽度 720px，自适应 2~6 行，聚焦时主色描边 |
| 提交方式 | `Enter` 提交；`Shift+Enter` 换行（移动端允许相反语义） |
| 空内容 | 去空白后为空 → **不提交**、不跳转、保持焦点、不产生错误提示 |
| 提交结果 | 跳转 `/chat?q=<encodeURIComponent(问题)>`，问题进入问答上下文 |
| 禁用条件 | 视图状态为 `empty` 或 `error` 时禁用；禁用时给出原因文案（非静默） |
| 全局快捷键 | `/` 或 `Ctrl/Cmd+K` 聚焦输入框；输入框已聚焦时按键不产生干扰 |
| 超长输入 | 文本域内部滚动，页面布局不被撑破 |

**实现约束**：使用 `@lobehub/ui/chat` 的 `ChatInputArea.Inner`（受控 TextArea）+ `ChatSendButton`，不使用 `ChatInputArea` 外层（其 `expand` 默认 `true` 会渲染全屏浮层）。

### 2.3 建议问题（FR-007）

| 状态 | 契约 |
|---|---|
| 可提问（`ready`） | 展示 4 条（2 条来自可检索文档标题 + 2 条预置），点击即提交并与输入框提交等价 |
| 不可提问（`empty`/`processing`/`error`） | 全部置灰，点击提示"先上传一份文档"（`empty`）或对应原因；**不得提交问题** |

### 2.4 问答上下文占位页（FR-006）

| 契约 | 说明 |
|---|---|
| 接收问题 | 从 `?q=` 读取并渲染为用户消息（`ChatItem placement="right"`） |
| 能力说明 | 明确呈现"检索问答能力尚未上线"的状态说明，**不得生成任何模拟答案或引用片段** |
| 缺失参数 | `?q=` 为空时展示引导返回首页提问 |
| 返回 | 提供返回首页的入口 |

### 2.5 知识导航层（FR-008/009）

| 元素 | 契约 |
|---|---|
| 最近更新列表 | 最多 6 条；每条含 `FileTypeIcon` + 标题（超 24 字符单行截断 + 悬停可见全名）+ 相对时间 |
| 点击条目 | 打开 `DocumentDrawer` 展示详情，**不离开首页**（不改变路由） |
| 浏览全部 | 提供入口指向 `/documents`（本期为占位页） |
| 空态（`empty`） | 整层替换为三步引导（上传 → 自动处理 → 提问）+ 上传入口 |
| 处理中（`processing`） | 正常展示列表，并在提问区提示"知识库正在处理中，部分问题可能没有结果" |
| 加载中（`loading`） | 列表区域用 `Skeleton`，**提问框不等待、不阻塞渲染** |

### 2.6 最近对话（FR-013/014）

| 契约 | 说明 |
|---|---|
| 数据源 | `localStorage`，最多 6 条，按时间倒序 |
| 展示 | 问题摘要（≤80 字符，单行截断）+ 相对时间 |
| 点击 | 恢复该会话（本期跳转 `/chat`，占位期至少带出原问题） |
| 无数据 | **整块不渲染**（不出现空容器、不占位留白） |

### 2.7 服务不可用（FR-012）

| 契约 | 说明 |
|---|---|
| 触发 | 列表请求失败（网络错误、5xx、`TENANT_*`） |
| 表现 | 顶部 `Alert`（error 语义）+ 明确文案 + 重试按钮；提问框禁用 |
| 区分 | 请求失败**不得**渲染为"知识库为空"（避免误导用户重复上传已有文档） |
| 恢复 | 重试成功后回到对应正常状态 |

### 2.8 上传（空态闭环所需的最小范围）

| 契约 | 说明 |
|---|---|
| 入口 | 空态引导卡 / 行动卡上的上传按钮 |
| 表单 | 文件选择（拖拽或点击）+ `docName`（默认文件名去扩展名，可编辑）+ 可选 `title` |
| 前置校验 | 类型/大小/文件名长度不合法时就地提示，**不发起请求** |
| 进行中 | 进度指示（XHR 上传进度） |
| 结果 | 按 `INGESTED`/`NOOP`/`PARTIAL`/`FAILED` 给出对应文案与后续动作（查看文档 / 去提问） |
| 202 降级 | 若收到 202，提示"已接收，正在后台处理"，**不判为失败、不轮询** |
| 成功后 | 重新拉取首页数据，使新文档出现在最近更新中、提问恢复可用 |

## 3. 状态契约

首页视图状态由数据维度与内容维度合成，取值与优先级见 `data-model.md` §3：

```
error  >  empty  >  processing  >  ready
```

**断言要求**：同一屏内不得同时出现互斥状态的表现（例如"知识库为空"与"服务不可用"同时展示）。

---

## 4. 响应式契约（FR-016）

| 断点 | 契约 |
|---|---|
| ≥ 1280px | 侧栏常驻；内容区最大 880px 居中 |
| 1024–1280px | 侧栏可折叠为图标栏 |
| 768–1024px | 侧栏收纳；导航层由左右分栏改为上下堆叠 |
| < 768px | 侧栏收为汉堡/底部导航；提问框全宽；建议问题显示 2 条；最近更新显示 4 条 |

**通用断言**：任一断点下**无横向滚动**，提问框与提交动作均可达。

---

## 5. 无障碍与键盘契约（FR-015）

| 项 | 契约 |
|---|---|
| 键盘可达 | 提问框、建议问题、最近更新条目、上传按钮、重试按钮均可键盘到达与触发 |
| 焦点可见 | 保留 Lobe UI 默认 focus ring（`ConfigProvider config.globalFocusRing` 默认开启，不得关闭） |
| 语义 | 列表使用列表语义；状态色不得作为唯一信息载体（同时有文字文案） |
| 快捷键 | `/` 与 `Ctrl/Cmd+K` 聚焦提问框；不得在输入状态下抢占按键 |

---

## 6. 禁止项（可自动断言，对应 FR-002 / SC-003）

在首页**任意状态**（loading / error / empty / processing / ready）下，渲染出的 DOM 中：

- 不得出现当前租户编码字符串；
- 不得出现"租户"字样；
- 不得出现租户选择/切换控件（`Select`、下拉、输入框等），除提问框与上传表单字段外；
- 不得出现登录、注册、账号相关入口。

**落地方式**：Vitest 渲染各状态后，断言 `document.body.textContent` 不匹配 `/租户|tenant/i`，且不包含测试租户编码常量。

## 7. 性能契约

| 项 | 契约 |
|---|---|
| 首屏 | 常规网络下 2 秒内可见可用提问框（SC-002）；概览数据未返回不阻塞提问框渲染 |
| 首屏 JS | gzip ≤ 400 KB；`@lobehub/ui` 的 `Markdown`（shiki/katex/mermaid）**不得进入首屏包** |
| 分包 | `manualChunks` 拆分 react 与 antd+lobehub；`/chat` 与占位页路由级懒加载 |
| 请求 | 首页只发 1 个只读请求（`size=6`），失败不重试风暴 |
